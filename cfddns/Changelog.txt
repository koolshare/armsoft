Koolshare arm 384 router software center CloudFlare DDNS Changelog
===========================================
1.0
   - add	添加koolshare armV7架构384梅林改版固件支持；
1.2
   - fix	修复当域名下不存在解析记录时更新失败的问题：查询不到记录时自动创建（POST），不再只做PUT更新；
   - fix	修复记录ID与IP提取逻辑过于脆弱导致的更新异常（如返回10405 Method not allowed）；
   - add	新增参数校验与CloudFlare接口返回值的统一判断，失败时输出原始返回便于排查；
1.3
   - add	新增「定时更新间隔」设置，支持每5/10/15/20/30分钟、每1/2/3/4/6/8/12小时、每天一次，自动检测公网IP变化并更新解析；
   - add	开启插件后自动创建cron定时任务，关闭插件或卸载时自动清理；
   - fix	修复原脚本中定时更新代码被注释、且缺少刷新间隔配置项，导致IP变化后无法自动更新的问题；
